# C Exercises

A collection of C programs I wrote while learning the language. Each file solves one problem, from basic input handling to data structures.

## How the repository is organized

Every `.c` file contains one exercise. The problem statement is written as a comment at the top of the file, so each file explains what it does and can be read on its own.

## What I learned

- **Unsigned numbers and bit operations:** how unsigned integers are stored, and how to work with them at the bit level.
- **Strings:** working with character arrays, reading and processing text character by character, and the standard string functions.
- **Pointers:** how addresses work, passing data to functions by pointer, pointer arithmetic, and dynamic memory.
- **Data structures:**
  - `struct`: grouping related values into one type
  - `union`: storing different types in the same memory
  - `enum`: naming sets of constant values
- **Text files:** opening, reading from and writing to text files, and closing them correctly.
- **Linked lists:** creating a list, adding nodes, and deleting nodes.

## How to compile and run

You need a C compiler such as GCC.

```
gcc file_name.c -o file_name
./file_name
```

On Windows, run `file_name.exe` instead of `./file_name`.

Most programs read their input from the keyboard. The expected input format is described in the comment at the top of each file.
